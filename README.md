# Quran Inspiration

Web publik inspirasi Al-Qur'an per surat: **Baca**, **Tonton**, **Dengarkan**.
Isi diambil otomatis dari folder Google Drive "Inspirasi Quran" dan channel YouTube @QuranInspiration setiap jam.

Panduan teknis lengkap ada di [CLAUDE.md](CLAUDE.md). Panduan pemasangan jembatan Google ada di [apps-script/PANDUAN.md](apps-script/PANDUAN.md).
